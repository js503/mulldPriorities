# Workshop artwork

`About/Preview.png` is a 1280 × 720 landscape cover shared by the in-game mod preview and Steam. It is under 1 MB. The original square identity artwork is retained as `docs/workshop/brand-square.png`.

Run `tools/Build-WorkshopAssets.ps1` to rebuild the wide cover and consistent real-game screenshot crops. Optional `-MockOutput` writes four layout alternatives outside the release folders.

The square illustration was generated with the built-in imagegen tool: lowercase “mulld”, capitalized “Priorities”, charcoal/cream/gold, a pawn work grid, priority numbers and a checkmark. The landscape composition and typography are built from that artwork without stretching the game screenshots.
